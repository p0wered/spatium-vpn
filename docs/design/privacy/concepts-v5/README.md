# Privacy technical graphic, iteration 5

One corrected browser-rendered SVG study inside the approved production Privacy composition.

## Corrections

- Encrypted traffic is a mirrored TX/RX byte histogram, not a glowing ECG-like trace.
- The technical SVG contains no glowing lines. Only tiny event points use a restrained halo.
- Site identity remains a discrete shared-IP state because it is a state, not a utilization metric.
- DNS leak prevention is a route-policy schematic: the client query passes through route and firewall control, IPv4 and supported IPv6 converge into the VPN tunnel, unsupported IPv6 is blocked, and the ISP DNS escape path is closed.
- Session memory is a stepped allocation series for an illustrative session buffer, not a claim about whole-system RAM utilization.
- Persistent storage is a zero-write event rail.
- The explanatory sentence is placed below the graphic, following the Bypass diagram composition.

## Factual boundaries

- DNS routing and IPv6 handling must match the final Spatium client implementation. If Spatium tunnels IPv6, use the IPv6 tunnel branch. If it does not support IPv6, show only the blocked branch.
- `SESSION BUFFER` is intentionally narrower and more defensible than a generic `RAM USAGE` claim.
- `0 WRITES` and no activity history remain product claims that require architecture and policy confirmation.
