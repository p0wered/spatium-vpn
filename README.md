# SpatiumVPN

Landing page + dashboard for a fictional VPN service. Portfolio project with a heavy focus on design: dark premium theme inspired by Apple's Liquid Glass aesthetic.

> All data and features are mocked — the VPN itself does not exist.

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Motion (Framer Motion) · React Router

## Development

```bash
npm install
npm run dev       # dev server (+ /dev — design system sandbox)
npm run build     # type-check + production build
npm run lint      # oxlint
npm run format    # prettier
```
